# 서·논술형 평가 연습실 · 무료 요금제용 안전한 합평 기능

기존 세 가지 연수 활동에 **「우리 문항 함께 합평하기」**를 추가한 버전입니다.
**Firebase Spark(무료 요금제)**로 사용하도록 Firebase Storage를 쓰지 않고, 합평 문서를 Firestore에 나누어 저장합니다.

## 주요 기능

1. **방 만들기와 승인제**: 방장이 6자리 방 번호를 만들고 선생님들이 입장 신청을 합니다. 방장이 승인한 계정만 합평 자료에 접근할 수 있습니다. 방장은 승인을 취소할 수 있습니다.
2. **문항·채점기준표 업로드**: PDF, JPG, PNG, WEBP 및 휴대전화 촬영 사진. 사진은 브라우저에서 다시 인코딩해 EXIF 위치정보를 제거합니다. **PDF 내부의 작성자/문서 속성은 자동 제거하지 않습니다.**
3. **위치별 피드백**: 문항에서 특정 부분을 클릭·터치한 뒤 의견 입력, 실시간 표시.
4. **방장 필터**: 방장이 작성자 한 명을 선택하면 모든 참여자 화면에 해당 작성자의 피드백만 보입니다. 삭제되는 것은 아닙니다.
5. **합평 결과 PDF 다운로드**: 문항 업로더가 모든 피드백 핀과 의견 목록을 함께 다운로드합니다. 방장 필터 상태와 무관하게 모든 의견이 포함됩니다.
6. **연수 종료 및 전체 삭제**: 방장이 종료하면 새로운 작성이 차단됩니다. 등록된 의견, 파일 조각, 문항, 참여자 정보, 방을 순서대로 삭제합니다. 네트워크 오류가 발생하면 방장이 해당 방에서 삭제 마무리를 다시 실행할 수 있습니다. 성공적으로 끝난 삭제는 복원할 수 없습니다.

## 배포 및 설정

1. **현재 Firebase Firestore 규칙을 먼저 백업하세요.** 동일 프로젝트를 다른 서비스에도 사용하고 있다면 규칙 전체 교체 전에 기존 규칙과 병합해야 합니다.
2. [Firebase Console](https://console.firebase.google.com/) → 해당 프로젝트 → **Authentication → Sign-in method → 익명(Anonymous) 활성화**.
3. **Firestore Database → 규칙(Rules)**에서 이 패키지의 `firestore.rules`를 적용하고 게시합니다. 방 승인 여부를 서버에서 검사하는 핵심이므로 **이 단계를 생략하면 보안이 적용되지 않습니다.**
4. 웹 호스팅(GitHub Pages 등)에 `index.html`, `peer.css`를 같은 폴더에 업로드합니다. 호스팅 도메인이 Firebase Authentication의 승인 도메인인지 확인합니다.
5. Firebase Storage / Blaze 유료 요금제는 필요하지 않습니다. PDF 렌더링을 위한 PDF.js 및 결과 PDF 제작을 위한 pdf-lib는 외부 CDN에서 불러오므로 인터넷 연결이 필요합니다.
6. **새 합평 방을 만들어** 사용합니다. 이전 버전에서 만든 방은 승인 상태 정보가 없어 새 버전에서 열 수 없으므로 자료를 다시 등록해야 합니다.
7. 연수 전 다른 기기 두 대로 실제로 테스트하세요: 방 생성 → 입장 요청 → 승인 전 접근 제한 확인 → 방장 승인 → 문항 업로드 → 피드백 → 필터 → PDF 다운로드 → 연수 종료 및 데이터 삭제. 실시간 Firebase 서버 통합테스트는 이 패키지 제작 환경에서 수행하지 못했습니다.

## 무료 요금제 및 용량 제한

- **PDF 최대 8MiB**(약 8.4MB), 사진은 자동 축소·JPEG 재인코딩 후 최대 8MiB.
- Firestore 문서 하나에 파일 바이너리를 최대 256KiB씩 나누어 저장하므로, PDF 한 개당 최대 32개 파일 조각이 생성됩니다.
- 파일 조회 인원이 많거나 PDF가 크면 Spark 무료 쓰기·읽기·전송량에 도달할 수 있습니다. 연수용 소규모 문서 공유에 적합한 절충안입니다.
- 연수 종료 시 업로더는 **먼저 결과 PDF를 다운로드**하고 방장이 삭제 버튼을 눌러주세요. 종료 후 삭제된 자료는 복구되지 않습니다.

## 개인정보·보안 주의사항

- **교사가 직접 만든 문항과 채점기준표**만 사용하고, 학생 이름·실제 답안·연락처·교사 개인식별 정보 등은 넣지 않는 것이 좋습니다. 실제 시험에 사용할 미공개 문항의 외부 공유도 학교 규정에 따라 확인하세요.
- 익명 로그인은 **실명 인증이 아닙니다.** 승인된 브라우저의 Firebase 인증 UID로 접근을 제어합니다. 방 번호가 유출되고 방장이 낯선 요청을 승인하면 자료를 읽을 수 있으니 신청자 확인 후 승인하세요.
- 표시 이름, 작성한 피드백 및 업로드 문서는 Firebase Firestore에 저장됩니다. 방장이 삭제하기 전에는 유지되며, 삭제 후에도 사용자가 이미 다운로드한 파일이나 별도로 저장한 사본은 지워지지 않습니다.
- 같은 브라우저 프로필이 아니거나 브라우저 데이터가 삭제되면 익명 UID가 바뀔 수 있습니다. 방장은 처음 방을 만든 브라우저를 유지하세요. 삭제 기능의 마무리도 방장 계정에서만 가능합니다.
- 기존 **실시간 공동 채점 기능**은 호환성을 위해 이전 공개 규칙을 그대로 유지했습니다. **보안 강화 범위는 새 합평방에 한정**됩니다. 채점 기능에도 개인정보를 넣어 운영하지 마세요.
- 더 높은 보안 수준(교사 신원 인증, 서버 자동 삭제, 활동 로그, 학교 통합 로그인 등)이 필요하면 별도 인증·서버 운영 설계가 필요합니다.

## 포함 파일

- `index.html` — 앱 본체, 기존 활동 + 합평 기능
- `peer.css` — 합평 및 모바일 UI 스타일
- `firestore.rules` — 합평 참여 승인, 자료 읽기/쓰기 및 종료 시 삭제 권한 규칙
